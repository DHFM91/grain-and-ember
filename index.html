Element rules

Every cell is one pixel of one element. Each tick, the grid is scanned bottom to top (alternating left/right per row so nothing drifts one way). A moving cell may swap into a neighbor if that neighbor is empty, or is a movable element with lower density (for falling) or higher density (for rising).
